# TP04 - Unity VR

Projet réalisé dans le cadre du cours ST2OOS.

## Fonctionnalités

- Configuration XR et OpenXR
- Interaction et saisie d'objets
- Déplacement en VR
- Interface utilisateur XR
- Arme VR avec système de tir
- Projectiles avec Rigidbody
- Cibles générées aléatoirement
- Détection des impacts
- Effets de particules
